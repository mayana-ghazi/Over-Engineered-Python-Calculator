# Over-Engineered Python Calculator

**Author:** Ghazi Mayana

A command-line calculator built entirely in Python. While it performs simple arithmetic operations, the core focus of this project is extreme edge-case handling and robust input validation. 

### Why "Over-Engineered"?
Instead of relying on advanced mechanics or loops, this calculator uses strict logic and control flow to anticipate and handle *every possible invalid user input*. It was built as a foundational project to master conditional statements and logical operators in Python without breaking or crashing.

### Features
* Basic arithmetic operations (Addition, Subtraction, Multiplication, Division).
* Bulletproof error handling for unexpected or invalid inputs.
* Pure logic-based architecture.
